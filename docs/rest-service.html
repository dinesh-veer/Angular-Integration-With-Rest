REST Service & Integration

Learn how AppServiceService queries the WordPress Public REST API using Angular's HttpClient and streams typed responses via RxJS Observables.

AppServiceService Implementation

The service encapsulates HTTP data access in a dedicated class: 

import { Injectable } from '@angular/core';
import { HttpClient } from '@angular/common/http';
import { Observable } from 'rxjs';
import { map } from 'rxjs/operators';

const API_URL = 'https://public-api.wordpress.com/rest/v1.1/sites/vocon-it.com/posts';

@Injectable({
  providedIn: 'root'
})
export class AppServiceService {
  protected restItemUrl: string = API_URL;

  constructor(private http: HttpClient) {}

  getAll(): Observable<any> {
    return this.http
      .get<any>(this.restItemUrl)
      .pipe(map((data) => data));
  }
}

The @Injectable({ providedIn: 'root' }) decorator provides this service at the root level, enabling Angular's dependency injection container to instantiate it as a singleton.

REST Endpoint

The service connects to the public WordPress REST API v1.1:

GET https://public-api.wordpress.com/rest/v1.1/sites/vocon-it.com/posts

This endpoint returns recent blog articles published on vocon-it.com in JSON format. No authentication header is required, making it an ideal live test target for REST integration.

Payload Structure

A typical response payload returned by the endpoint:

{
  "found": 148,
  "posts": [
    {
      "ID": 7108,
      "title": "Enable User Namespaces in Kubernetes — security...",
      "content": "<p>User namespaces are a Linux kernel feature that isolates user and group IDs...</p>",
      "date": "2025-05-07T11:50:43+00:00",
      "author": {
        "name": "Oliver Veits"
      }
    }
  ]
}

RxJS Observable vs. Promises

Angular's HttpClient returns cold RxJS Observable instances instead of standard JavaScript Promises:

  • Lazy Execution: HTTP requests are not dispatched until .subscribe() is called.
  • Cancellable: Unsubscribing cancels the in-flight XHR/fetch request immediately.
  • Composability: RxJS operators such as map(), catchError(), retry(), and debounceTime() can transform the stream declaratively.

Component Usage

The AppComponent injects the service and subscribes to the stream: 

export class AppComponent implements OnInit {
  title = 'Hello-Angular';
  restItems: any;
  selectedContent = '';

  constructor(
    private appService: AppServiceService,
    private cdr: ChangeDetectorRef
  ) {}

  ngOnInit(): void {
    this.getRestItems();
  }

  getRestItems(): void {
    this.appService.getAll().subscribe({
      next: (restItems) => {
        this.restItems = restItems;
        this.cdr.markForCheck();
      },
      error: (err) => {
        console.error('Failed to load blog posts:', err);
      }
    });
  }
}
