Application Providers (app.config.ts)

In standalone Angular, application-wide services and providers are configured inside src/app/app.config.ts: 

import { ApplicationConfig, provideBrowserGlobalErrorListeners, provideZoneChangeDetection } from '@angular/core';
import { provideHttpClient } from '@angular/common/http';

export const appConfig: ApplicationConfig = {
  providers: [
    provideZoneChangeDetection({ eventCoalescing: true }),
    provideBrowserGlobalErrorListeners(),
    provideHttpClient()
  ]
};
  • provideHttpClient(): Configures Angular's HTTP client without requiring HttpClientModule.
  • provideZoneChangeDetection(): Tunes Zone.js change detection with eventCoalescing: true to bundle multiple synchronous DOM events into a single change detection cycle.
  • provideBrowserGlobalErrorListeners(): Automatically captures uncaught global errors for enhanced runtime debugging.

Zone.js & Polyfill Management

In modern Angular, polyfills.ts is no longer required. Instead, polyfills are declared as an array under options.polyfills in angular.json: 

"polyfills": [
  "zone.js"
]

This ensures that Zone.js is bundled into a dedicated polyfills chunk (e.g., polyfills-LVNOU2XZ.js) loaded before the main application logic executes.

TypeScript Configuration

TypeScript compilation is structured using modern project references:

  • tsconfig.json: Base compiler options (target: ES2022, module: preserve, strict mode enabled).
  • tsconfig.app.json: Compilation rules for application source files (excludes *.spec.ts).
  • tsconfig.spec.json: Compilation rules for unit tests (includes vitest/globals type definitions).
