Getting Started

Learn how to set up your local development environment, install project dependencies, start the Angular dev server, and build for production.

Prerequisites

Ensure that you have the following installed on your operating system:

  • Node.js: v20.19+, v22.12+, or v24.x (Recommended: Node.js 22 LTS or Node.js 24)
  • npm: v10.x or v11.x
  • Git: for source control and cloning

Verify your Node and npm versions in your terminal:

node -v
npm -v

1. Clone Repository

Clone the repository from GitHub to your local machine:

git clone https://github.com/dinesh-veer/Angular-Integration-With-Rest.git
cd Angular-Integration-With-Rest

2. Install Dependencies

Install the required npm packages:

npm install

This installs Angular 21, TypeScript 5.9, RxJS 7.8, Zone.js, and Vitest for testing.

3. Development Server

To run the development server with live reload:

npm start

Alternatively, if you have Angular CLI installed globally, you can run: 

ng serve

Open your browser and navigate to: 

http://localhost:4200/

The application will automatically detect changes to source files and refresh the browser.

4. Production Build

To compile the project for production deployment:

npm run build

The compiled static assets (HTML, CSS, JavaScript bundles) are output to: 

dist/hello-angular/browser

The modern @angular/build:application builder automatically optimizes chunks, extracts CSS, treeshakes unused code, and creates hash-versioned assets.

5. Preview Production Build

You can test the static production build locally using any HTTP server:

npx serve dist/hello-angular/browser

Or with Python:

python3 -m http.server 8080 --directory dist/hello-angular/browser

6. Run Unit Tests

Run the automated unit test suite using Vitest:

npm test

All tests for AppComponent and AppServiceService will execute in headless JSDOM mode and report status in the terminal.
