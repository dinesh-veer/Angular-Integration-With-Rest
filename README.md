# Angular Integration with REST Services

This project is built with [Angular](https://angular.dev/).

## Development server

Run `npm start` (or `ng serve`) for a dev server. Navigate to `http://localhost:4200/`. The app will automatically reload if you change any of the source files.

## Build

Run `npm run build` (or `ng build`) to build the project. The build artifacts will be stored in the `dist/hello-angular` directory.

## Running unit tests

Run `npm test` to execute the unit tests via [Vitest](https://vitest.dev).
